# Escola de SEO - extracao e implementacao

Ferramentas e plano de implementacao para montar um servico de posicionamento no Google Meu Negocio.

Este repositorio NAO contem o conteudo do curso. Modulos, transcricoes, anexos e materiais ficam fora do Git.

- `PROMPT-EXTRACAO*.md`: prompts para a extensao Claude in Chrome
- `02-TEMPLATES/`: template de nota por aula
- `03-IMPLEMENTACAO/`: processo, entregaveis, precificacao e pitch (trabalho proprio)
- `04-FERRAMENTAS/`: scripts de gravacao e transcricao local
